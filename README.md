# F&B Market Case Study — North America

A consulting-style case study analyzing the food & beverage (F&B) market in North America: flavor classification, product positioning, and a proposed product launch, brought together from spreadsheet analysis into a written case study with recommendations.

## Repository contents

| File | Description |
|---|---|
| `Consultant case study.docx` | Written case study — problem framing, approach, and recommendations |
| `F&B in North America.ipynb` | Data analysis notebook |
| `Master.xlsx` | Consolidated dataset used across the analysis |
| `Flavor Classification.xlsx` | Flavor category / segmentation data |
| `Positioning Category Mapping.xlsx` | Product positioning and category mapping |
| `Product Launch Dataset.xlsx` | Data supporting the product launch recommendation |

## Approach

The analysis combines structured spreadsheet data (flavor segmentation, positioning, and product launch data) with exploratory analysis in the notebook, then brings the findings together into a written, consultant-style case study with a final recommendation.

## Tools

Python (pandas, Jupyter) · Excel · Written case-study reporting
